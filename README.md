# 👋 Sobre mim

Sou formado em **Gestão Pública** e atualmente direciono minha carreira para o **Desenvolvimento de Software**.

Tenho experiência prática no desenvolvimento de aplicações web, APIs e ambientes Docker, sempre buscando escrever código organizado, escalável e de fácil manutenção.

Meu foco atual está no ecossistema **Node.js**, utilizando tecnologias modernas para construir aplicações completas, desde o banco de dados até a interface.

Atualmente estudo e desenvolvo projetos utilizando:

* Arquitetura em camadas
* APIs REST
* Docker
* PostgreSQL
* Prisma ORM
* Next.js

Acredito que aprender continuamente e resolver problemas de forma estruturada são as habilidades mais importantes para evoluir como desenvolvedor.
